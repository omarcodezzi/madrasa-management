# MMS ডেটাবেস

ডেটাবেসের নাম **MMS** (মাদরাসা ম্যানেজমেন্ট সিস্টেম), Microsoft SQL Server 2019/2022 (Express সংস্করণেও চলে)।

| ফাইল | কী |
|---|---|
| [`database/MMS.sql`](../database/MMS.sql) | **পুরো স্ক্রিপ্ট:** ডেটাবেস তৈরি, সব টেবিল, কী, ইনডেক্স, শুরুর ডেটা, ভিউ, ফাংশন ও স্টোরড প্রসিডিউর। বারবার চালানো নিরাপদ। |
| [`database/schema.sql`](../database/schema.sql) | একই জিনিস, কিন্তু ডেটাবেস তৈরি ছাড়া (আগে থেকে থাকা ডেটাবেসে চালানোর জন্য) |
| `database/build.sh` | মাইগ্রেশন যোগ করার পর ওপরের দুটি ফাইল নতুন করে তৈরি করে |
| `backend/src/Madrasa.Infrastructure/Persistence/Sql/ReportingObjects.sql` | ভিউ ও প্রসিডিউরের মূল সোর্স |

## চালানো
- **SSMS / Azure Data Studio:** `MMS.sql` খুলে Execute (F5)।
- **কমান্ড লাইনে:** `sqlcmd -S localhost -U sa -P "<পাসওয়ার্ড>" -C -i database/MMS.sql`
- তারপর অ্যাপের কানেকশন স্ট্রিংয়ে `Database=MMS` (ডিফল্ট এখন এটাই) দিয়ে API চালু করুন। স্ক্রিপ্টে `__EFMigrationsHistory` থাকে, তাই অ্যাপ বুঝে নেয় সব টেবিল আছে।
- স্ক্রিপ্ট না চালালেও চলে: API প্রথমবার চালু হলে নিজেই MMS ডেটাবেস ও সব টেবিল তৈরি করে।

**স্ক্রিপ্টে যা নেই:** রোল/অনুমতি আর প্রথম অ্যাডমিন ইউজার। পাসওয়ার্ড নিরাপদে হ্যাশ করতে হয় বলে এগুলো API প্রথমবার চালু হওয়ার সময় তৈরি করে (`Seed__AdminPassword` সেটিং থেকে)।

## ভিউ, ফাংশন ও স্টোরড প্রসিডিউর
সবগুলো শুধু পড়ে; Excel, Power BI বা SSMS থেকে রিপোর্ট নিতে কাজে লাগে।

| নাম | কাজ | উদাহরণ |
|---|---|---|
| `vw_CurrentStudents` | চলতি বছরের সব শিক্ষার্থী, শ্রেণি, রোল, অভিভাবক ও মোবাইল | `SELECT * FROM vw_CurrentStudents` |
| `vw_FeeDues` | প্রতিটি বকেয়া ফি | `SELECT * FROM vw_FeeDues WHERE Month = '2026-11'` |
| `vw_FundBalances` | ফান্ড অনুযায়ী ব্যালান্স | `SELECT * FROM vw_FundBalances` |
| `vw_MonthlyLedger` | মাস ও খাত অনুযায়ী আয়-ব্যয় | `SELECT * FROM vw_MonthlyLedger ORDER BY Month DESC` |
| `fn_StudentDue(@id)` | একজনের মোট বকেয়া | `SELECT dbo.fn_StudentDue(1)` |
| `fn_CurrentSessionId()` | চলতি শিক্ষাবর্ষ | |
| `usp_DashboardSummary` | এক লাইনে আজকের সারসংক্ষেপ | `EXEC usp_DashboardSummary` |
| `usp_DailyAttendance` | শ্রেণি অনুযায়ী দিনের হাজিরা | `EXEC usp_DailyAttendance '2026-11-23'` |
| `usp_StudentAttendance` | একজনের হাজিরা ও মোট | `EXEC usp_StudentAttendance 1, '2026-11-01', '2026-11-30'` |
| `usp_MonthlyCollection` | মাসের ফি আদায় | `EXEC usp_MonthlyCollection '2026-11'` |
| `usp_DueList` | বকেয়া তালিকা, অভিভাবকের মোবাইলসহ | `EXEC usp_DueList NULL` |
| `usp_LedgerStatement` | আয়-ব্যয় বিবরণী, চলমান ব্যালান্সসহ | `EXEC usp_LedgerStatement '2026-11-01', '2026-11-30', NULL` |
| `usp_ExamMeritList` | পরীক্ষার মেধা তালিকা | `EXEC usp_ExamMeritList 1, NULL` |
| `usp_SalarySheet` | মাসের বেতন শিট | `EXEC usp_SalarySheet '2026-11'` |
| `usp_BackupDatabase` | পুরো ব্যাকআপ ও যাচাই | `EXEC usp_BackupDatabase N'D:\Backup'` |

অ্যাপ নিজে EF Core দিয়ে টেবিলগুলো পড়ে-লেখে, তাই ব্যবসার নিয়ম (ফান্ডের বেশি খরচ না করা, রসিদ নম্বর, অনুমতি) অ্যাপের ভেতরে থাকে। এই অবজেক্টগুলো রিপোর্ট আর রক্ষণাবেক্ষণের জন্য।
